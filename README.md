# Re Market · Marketing digital e innovación

Sitio web de Re Market: planos interactivos, recorridos virtuales 360°, sitios web, landing pages y publicidad para proyectos inmobiliarios.

## Contenido
- `index.html`: el sitio completo (HTML, CSS y JS en un solo archivo).
- `img/`: fotos de proyectos, capturas de sitios y piezas publicitarias.

## Publicar con GitHub Pages
Settings → Pages → Branch: `main`, carpeta `/ (root)` → Save.
